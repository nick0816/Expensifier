# Simon's Expensifier

An audio effect that does absolutely nothing to your audio. Turning the knob from
**Cheap** to **Expensive** makes the gold crown and the `$$$` glow brighter.
The knob is a normal, automatable host parameter ("Expense"); double-click it to reset.

Formats: **VST3** (Cubase, Nuendo, Ableton, Studio One, Reaper, FL Studio, Bitwig, …),
**AAX** (Pro Tools), **AU** (Logic, GarageBand — macOS builds only) and a Standalone app.

## Layout

| Path | What |
|---|---|
| `Source/` | JUCE processor (pass-through) and editor (artwork, knob, glow) |
| `Resources/original.png` | the source artwork |
| `Resources/background.png`, `glow_*.png` | generated by `python tools/make_assets.py` (needs Pillow) |
| `JUCE/` | JUCE 8.0.4: `git clone --depth 1 --branch 8.0.4 https://github.com/juce-framework/JUCE.git JUCE` |

## Build: Windows (VST3, AAX, Standalone)

```
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

Output: `build/SimonsExpensifier_artefacts/Release/{VST3,AAX,Standalone}/`.

> On this machine the VS 2022 install is flagged "incomplete" by the VS installer, so CMake
> can't find it automatically. Workaround (pre-configures JUCE's helper tool too):
> ```
> $inst = "C:/Program Files/Microsoft Visual Studio/2022/Community,version=17.9.34728.123"
> cd JUCE; cmake . -B ../build/JUCE/tools -G "Visual Studio 17 2022" -A x64 "-DCMAKE_GENERATOR_INSTANCE=$inst" -DJUCE_BUILD_HELPER_TOOLS=ON; cd ..
> cmake -S . -B build -G "Visual Studio 17 2022" -A x64 "-DCMAKE_GENERATOR_INSTANCE=$inst"
> ```
> Repairing VS 2022 in the Visual Studio Installer makes this unnecessary.

## Build: macOS without owning a Mac (GitHub Actions)

Push this folder to a GitHub repo. [.github/workflows/build-mac.yml](.github/workflows/build-mac.yml)
builds a universal (Apple Silicon + Intel) AU, VST3 and AAX, runs Apple's `auval` check on the AU,
and uploads the zips under **Actions → latest run → Artifacts → SimonsExpensifier-macOS**.

The builds are ad-hoc signed, not notarized, so on the Mac, after unzipping, run once:
```
xattr -dr com.apple.quarantine "Simons Expensifier.component"
cp -R "Simons Expensifier.component" ~/Library/Audio/Plug-Ins/Components/
```
then restart Logic (it rescans in Settings → Plug-in Manager).

## Build: macOS (AU for Logic, plus VST3, AAX)

```
cmake -S . -B build -G Xcode
cmake --build build --config Release
```

## Install

| Host | Copy | To |
|---|---|---|
| Cubase & other VST3 hosts (Win) | `Simons Expensifier.vst3` folder | `C:\Program Files\Common Files\VST3\` |
| Cubase & other VST3 hosts (Mac) | `Simons Expensifier.vst3` | `~/Library/Audio/Plug-Ins/VST3/` |
| Logic (Mac only) | `Simons Expensifier.component` | `~/Library/Audio/Plug-Ins/Components/` |
| Pro Tools (Win) | `Simons Expensifier.aaxplugin` folder | `C:\Program Files\Common Files\Avid\Audio\Plug-Ins\` |
| Pro Tools (Mac) | `Simons Expensifier.aaxplugin` | `/Library/Application Support/Avid/Audio/Plug-Ins/` |

**Pro Tools note:** retail Pro Tools only loads AAX plugins signed with PACE's `wraptool`
(free Avid developer account + PACE signing account required). Unsigned builds load only
in the *Pro Tools Developer* build.
